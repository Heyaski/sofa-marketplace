# 📦 Как добавить 3D модель в базу данных

Есть **два способа** добавить 3D модель в БД:

## 🎯 Способ 1: Через админку Django (простой способ)

### Шаг 1: Откройте админ-панель

1. Перейдите по адресу: `http://localhost:8000/admin/` (или ваш домен)
2. Войдите в систему с правами администратора

### Шаг 2: Добавьте файл 3D модели

1. В левом меню найдите раздел **"Catalog"** (Каталог)
2. Нажмите на **"Файловые ресурсы"** (File assets)
3. Нажмите кнопку **"+ Добавить файловый ресурс"** (Add file asset)

### Шаг 3: Заполните форму

Заполните следующие поля:

- **ID файла** (обязательно) - уникальный идентификатор, например:

  - `model_001`
  - `sofa_comfort_3d`
  - `chair_3d_model`

  ⚠️ **Важно:** ID должен быть уникальным! Используйте понятные названия.

- **Тип файла** (обязательно) - выберите **"3D Модель"**

- **Файл** (обязательно) - нажмите "Выберите файл" и загрузите ваш 3D файл:

  - `.glb` ✅ (рекомендуется - лучшая поддержка)
  - `.gltf` ✅
  - `.usdz` ✅ (для iOS)
  - `.fbx` ⚠️ (не поддерживается для просмотра в браузере, но можно скачать)
  - `.rfa` ⚠️ (не поддерживается для просмотра в браузере, но можно скачать)

- **Описание** (необязательно) - например: "3D модель дивана Комфорт"

### Шаг 4: Сохраните

Нажмите кнопку **"Сохранить"** (Save)

✅ **Готово!** Файл добавлен в БД.

---

## 🎯 Способ 2: Через Excel импорт (массовая загрузка)

Этот способ удобен, если нужно загрузить много файлов сразу.

### Шаг 1: Подготовьте файлы

1. Создайте папку `backend/import_files/` (если её нет)
2. Поместите туда все ваши 3D файлы, например:
   ```
   backend/import_files/
   ├── sofa_comfort.glb
   ├── chair_relax.glb
   └── table_modern.glb
   ```

### Шаг 2: Создайте Excel файл

Создайте файл с листом **"Файлы"** (или **"Files"**):

| ID файла  | Тип      | Имя файла        | Описание         |
| --------- | -------- | ---------------- | ---------------- |
| model_001 | 3d_model | sofa_comfort.glb | 3D модель дивана |
| model_002 | 3d_model | chair_relax.glb  | 3D модель кресла |
| model_003 | 3d_model | table_modern.glb | 3D модель стола  |

**Колонки:**

- **ID файла** - уникальный идентификатор
- **Тип** - `3d_model` (или `3d`, `model`, `3д`, `модель`)
- **Имя файла** - точное имя файла из папки `import_files/`
- **Описание** - необязательно

### Шаг 3: Импортируйте через админку

1. Откройте админ-панель: `http://localhost:8000/admin/`
2. Перейдите в **"Продукты"** (Catalog → Products)
3. Нажмите кнопку **"📥 Импорт из Excel"**
4. Выберите ваш Excel файл
5. Нажмите **"Импортировать"**

✅ **Готово!** Все файлы будут загружены автоматически.

## 🔗 Как связать 3D модель с товаром

После того, как вы добавили 3D модель в БД, нужно связать её с товаром.

### Вариант 1: Через редактирование товара в админке

1. Откройте товар в админке: **Catalog → Products**
2. Найдите товар и нажмите на него для редактирования
3. В разделе **"Файловые ресурсы (ID из таблицы FileAsset)"**
4. В поле **"ID 3D моделей"** укажите ID вашей модели:
   - Одна модель: `model_001`
   - Несколько моделей: `model_001,model_002` (через запятую)
5. Нажмите **"Сохранить"**

### Вариант 2: Через Excel импорт товаров

В Excel файле с товарами укажите ID 3D моделей в колонке **"ID 3D моделей"**:

| Название        | Цена  | ID изображений | **ID 3D моделей** | ID категории |
| --------------- | ----- | -------------- | ----------------- | ------------ |
| Диван "Комфорт" | 50000 | img_001        | **model_001**     | 1            |

## ✅ Проверка результата

После добавления 3D модели и связывания с товаром:

1. **Проверьте API:**

   ```
   GET http://localhost:8000/api/catalog/products/1/
   ```

   В ответе должно быть поле `asset_3d_models`:

   ```json
   {
   	"asset_3d_models": [
   		{
   			"asset_id": "model_001",
   			"file_type": "3d_model",
   			"file_url": "http://localhost:8000/media/assets/model_001.glb"
   		}
   	]
   }
   ```

2. **Проверьте на сайте:**
   - Откройте страницу товара
   - Кнопка **"Открыть 3D Viewer"** должна быть активна
   - При клике должно открыться модальное окно с 3D моделью

## 💡 Полезные советы

1. **Рекомендуемые форматы:**

   - `.glb` - лучшая поддержка в браузере, один файл
   - `.gltf` - хорошая поддержка, но может требовать дополнительные файлы
   - `.usdz` - для iOS устройства

2. **Неподдерживаемые форматы:**

   - `.fbx`, `.rfa` - можно загрузить в БД, но просмотр в браузере недоступен
   - Для этих форматов будет показана кнопка "Скачать файл"

3. **Именование ID:**

   - Используйте понятные названия: `sofa_comfort_3d`, `chair_modern_glb`
   - Избегайте пробелов и специальных символов
   - Можно использовать цифры: `model_001`, `3d_sofa_01`

4. **Множественные модели:**
   - Один товар может иметь несколько 3D моделей
   - Укажите ID через запятую: `model_001,model_002,model_003`
   - В модальном окне можно будет переключаться между моделями

## 🐛 Решение проблем

**Проблема:** Кнопка "Открыть 3D Viewer" неактивна  
**Решение:**

- Проверьте, что у товара указаны ID 3D моделей в поле `model_3d_asset_ids`
- Проверьте, что FileAsset с таким ID существует в БД

**Проблема:** 3D модель не загружается в браузере  
**Решение:**

- Проверьте формат файла (должен быть .glb, .gltf или .usdz)
- Проверьте, что файл не поврежден
- Проверьте консоль браузера на ошибки

**Проблема:** Файл не найден при импорте из Excel  
**Решение:**

- Убедитесь, что файл находится в папке `backend/import_files/`
- Проверьте, что имя файла в Excel точно совпадает с именем файла на диске
- Проверьте регистр букв (Linux чувствителен к регистру)
