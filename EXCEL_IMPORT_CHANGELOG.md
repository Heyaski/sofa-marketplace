# 📦 Обновление: Система импорта товаров из Excel

## 🎉 Что нового?

Реализована полноценная система массового импорта товаров через Excel файлы с отдельным хранилищем файлов.

### ✨ Основные возможности

1. **Импорт товаров из Excel**

   - Загрузка товаров пачками через .xlsx файлы
   - Автоматическое создание или обновление существующих товаров
   - Подробные отчеты об успехах и ошибках

2. **Хранилище файлов с ID**

   - Централизованное хранение изображений и 3D моделей
   - Уникальные ID для каждого файла
   - Возможность переиспользования файлов между товарами

3. **Связь через ID**

   - Товары ссылаются на файлы через ID (не через прямую загрузку)
   - Множественные изображения и 3D модели на один товар
   - Простое указание в Excel: `img_001,img_002,img_003`

4. **API интеграция**
   - Автоматическая отдача файлов через API
   - Новые поля: `asset_images` и `asset_3d_models`
   - Полная обратная совместимость с существующими API

## 🗄️ Изменения в базе данных

### Новая таблица: catalog_fileasset

| Поле        | Тип          | Описание               |
| ----------- | ------------ | ---------------------- |

```typescript
// Получение товара с файлами
const product = await fetch('/api/catalog/products/1/').then(r => r.json())

// Отображение всех изображений
product.asset_images.forEach(img => {
	console.log(`Изображение ${img.asset_id}: ${img.file_url}`)
})

// Загрузка 3D модели
const model3d = product.asset_3d_models[0]?.file_url
if (model3d) {
	loadThreeJSModel(model3d)
}
```

## ⚙️ Технические детали

### Форматы файлов

**Изображения:**

- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

**3D модели:**

- glTF Binary (.glb) ← рекомендуется для веба
- glTF (.gltf)
- Wavefront (.obj)
- FBX (.fbx)

### Ограничения

- Excel файл: формат .xlsx (Excel 2007+)
- Размер файла: по умолчанию до 10MB (настраивается в Django settings)
- ID файлов: до 50 символов, уникальные
- ID в Excel: до 500 символов на поле (можно указать много файлов)

## 🐛 Известные ограничения

1. **Синхронный импорт:** Большие файлы (5000+ строк) могут занять время

   - **Решение:** В будущем можно добавить Celery для асинхронного импорта

2. **Нет автоматической валидации ID:** Excel может содержать несуществующие ID

   - **Решение:** Файлы просто не будут отображаться, ошибки не будет

3. **Нет версионирования файлов:** При замене файла старый удаляется
   - **Решение:** Используйте разные ID для версий (img_001_v1, img_001_v2)
