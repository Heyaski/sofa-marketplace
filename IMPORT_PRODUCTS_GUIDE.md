# Руководство по импорту товаров из Excel

## 📋 Обзор

Система позволяет массово импортировать товары через Excel файлы и управлять файловыми ресурсами (изображениями и 3D моделями) через уникальные ID.

## 🎯 Основной процесс

### Шаг 1: Загрузка файловых ресурсов

1. Перейдите в админ-панель Django: `http://ваш-домен/admin/`
2. Откройте раздел **"Файловые ресурсы"** (File assets)
3. Нажмите **"Добавить файловый ресурс"**
4. Заполните поля:
   - **ID файла**: уникальный идентификатор (например: `img_001`, `model_001`)
   - **Тип файла**: выберите "Изображение" или "3D Модель"
   - **Файл**: загрузите файл
   - **Описание**: (опционально) краткое описание

**Примеры ID файлов:**

- Для изображений: `img_001`, `img_002`, `sofa_red_main`, `chair_blue_01`
- Для 3D моделей: `model_001`, `3d_sofa_comfort`, `chair_3d_001`

### Шаг 2: Подготовка Excel файла

Создайте Excel файл (.xlsx) со следующими колонками:

| A        | B        | C    | D              | E             | F            | G        | H     | I    |
| -------- | -------- | ---- | -------------- | ------------- | ------------ | -------- | ----- | ---- |
| Название | Материал | Цена | ID изображений | ID 3D моделей | ID категории | Описание | Стиль | Цвет |

**Описание колонок:**

1. **Название** (обязательно) - название товара
2. **Материал** - материал изделия (например: "Ткань", "Кожа", "Велюр")
3. **Цена** (обязательно) - цена в числовом формате (например: 50000, 35000.50)
4. **ID изображений** - ID изображений через запятую (например: `img_001,img_002,img_003`)
5. **ID 3D моделей** - ID 3D моделей через запятую (например: `model_001,model_002`)
6. **ID категории** - ID существующей категории из базы данных
7. **Описание** - подробное описание товара
8. **Стиль** - стиль изделия (например: "Современный", "Классический")
9. **Цвет** - цвет изделия (например: "Синий", "Белый")

### Шаг 3: Импорт товаров

1. Перейдите в раздел **"Продукты"** в админ-панели
2. Нажмите кнопку **"📥 Импорт из Excel"**
3. Выберите подготовленный Excel файл
4. Нажмите **"Импортировать"**
5. Дождитесь завершения импорта и проверьте результаты

## 🔄 Логика работы

### Приоритет изображений

Когда товар запрашивается через API, система возвращает изображения в следующем приоритете:

1. **Изображения из FileAsset** (по ID из поля `image_asset_ids`)
2. **Изображения из ProductImage** (старая система множественных изображений)
3. **Основное изображение** (поле `image` для обратной совместимости)

### API ответ

При запросе товара через API вы получите:

```json

  "id": 1,
  "title": "Диван 'Комфорт'",
  "price": "50000.00",
  "material": "Ткань",

  "images": [...],
  "asset_images": [
    {
      "asset_id": "img_001",
      "file_type": "image",
      "file_url": "http://domain.com/media/assets/img_001.jpg",
```

## ⚠️ Важные замечания

1. **Уникальность ID**: Каждый файловый ресурс должен иметь уникальный ID
2. **Создание категорий**: Убедитесь, что категории созданы до импорта товаров
3. **Формат файла**: Используйте только формат .xlsx (Excel 2007+)
4. **Заголовки**: Первая строка Excel файла с заголовками будет пропущена
5. **Обновление товаров**: Если товар с таким названием уже существует, он будет обновлен

## 🐛 Устранение неполадок

### Ошибка: "Категория с ID X не найдена"

**Решение:** Создайте категорию с указанным ID или оставьте поле пустым (будет создана категория "Без категории")

### Ошибка: "No module named 'openpyxl'"

**Решение:** Установите библиотеку: `pip install openpyxl==3.1.5`

### Файлы не отображаются

**Решение:** Проверьте, что:

1. Файлы загружены в раздел "Файловые ресурсы"
2. ID файлов в Excel совпадают с ID в базе данных
3. Нет лишних пробелов в ID

## 📚 Дополнительная информация

### Форматы 3D моделей

Рекомендуемые форматы для 3D моделей:

- `.glb` / `.gltf` - для WebGL и Three.js
- `.obj` - универсальный формат
- `.fbx` - для сложных моделей

### Оптимизация изображений

Рекомендации для изображений:

- Формат: JPEG для фотографий, PNG для изображений с прозрачностью
- Размер: не более 2000x2000 пикселей
- Качество: 85-90% для JPEG
- Оптимизируйте перед загрузкой для ускорения работы сайта

## 🎨 Расширение функционала

Для добавления валидации данных при импорте, модифицируйте метод `import_excel` и добавьте проверки перед созданием/обновлением товаров.
