# Настройка интеграции с ЮКассой

## Шаг 1: Получение учетных данных

1. Зарегистрируйтесь в [личном кабинете ЮКассы](https://yookassa.ru/)
2. Получите:
   - **Идентификатор магазина** (account_id)
   - **Секретный ключ** (secret_key)

## Шаг 2: Настройка переменных окружения

Добавьте в файл `.env` в директории `backend/`:

```env
# Настройки ЮКассы
YOOKASSA_ACCOUNT_ID=ваш_идентификатор_магазина
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
YOOKASSA_TEST_MODE=1  # 1 для тестового режима, 0 для продакшена
```

## Шаг 3: Установка зависимостей

```bash
cd backend
pip install -r requirements.txt
```

## Шаг 4: Применение миграций

```bash
python manage.py migrate
```

## Шаг 5: Настройка Webhook (для продакшена)

1. В личном кабинете ЮКассы перейдите в раздел "Настройки" → "Уведомления"
2. Добавьте URL для webhook: `https://ваш-домен.ru/api/subscriptions/yookassa/webhook/`
3. Выберите события: `payment.succeeded`

## Шаг 6: Тестирование

### Тестовые карты для проверки:

- **Успешная оплата**: `5555555555554444` (любой CVC, любая дата в будущем)
- **Отклоненная карта**: `5555555555554477`

### Проверка работы:

1. Выберите тариф подписки на сайте
2. Нажмите "Оплатить"
3. Введите тестовые данные карты
4. После успешной оплаты подписка должна активироваться автоматически

## Шаг 7: Настройка автоматической проверки истекших подписок

Добавьте в cron (Linux) или Task Scheduler (Windows) задачу для проверки истекших подписок:

```bash
# Запускать каждый день в 00:00
0 0 * * * cd /path/to/backend && python manage.py check_expired_subscriptions
```

Или используйте Celery для периодических задач.

## API Endpoints

### Создание платежа

```
POST /api/subscriptions/create_payment/
Body: {
    "subscription_type": "basic" | "premium",
    "return_url": "https://your-site.com/profile/subscription"
}
```

### Проверка статуса платежа

```
POST /api/subscriptions/check_payment_status/
Body: {
    "payment_id": "23d93cac-000f-5000-8000-126628f15141"
}
```

### Webhook (для ЮКассы)

```
POST /api/subscriptions/yookassa/webhook/
```

## Важные замечания

1. **Тестовый режим**: По умолчанию включен тестовый режим. Для продакшена установите `YOOKASSA_TEST_MODE=0`
2. **Безопасность**: Никогда не храните секретный ключ в коде. Используйте переменные окружения
3. **Webhook**: В продакшене обязательно настройте webhook для автоматической активации подписок
4. **Автопродление**: Текущая реализация включает базовую поддержку автопродления. Для полноценной работы с рекуррентными платежами потребуется дополнительная настройка в личном кабинете ЮКассы

## Структура подписок

- **Пробная (trial)**: 3 модели, бесплатно, без ограничений по времени
- **Базовая (basic)**: 10 моделей в месяц, 1000 руб/мес, 30 дней
- **Премиум (premium)**: Безлимит, 8000 руб/мес, 30 дней

## Устранение неполадок

1. **Ошибка "YOOKASSA_ACCOUNT_ID и YOOKASSA_SECRET_KEY должны быть настроены"**

   - Проверьте, что переменные окружения установлены правильно
   - Перезапустите сервер после изменения .env

2. **Платеж создан, но подписка не активируется**

   - Проверьте логи сервера
   - Убедитесь, что webhook настроен правильно
   - Проверьте статус платежа вручную через API

3. **Подписка истекла, но не вернулась к пробной**
   - Запустите команду `python manage.py check_expired_subscriptions` вручную
   - Проверьте, что задача настроена в cron/Task Scheduler
