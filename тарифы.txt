#### 1. Общая информация

- Тарифы:
Free (постоянный), 
Trial (14 дней), 
Базовый, 
Pro  

- Оплата только через ЮKassa (уже подключена на расчётный счёт юрлица)  
- Обязательно реализовать оплату по СБП с QR-кодом для юрлиц (безналичный перевод с расчётного счёта)  
- Платежи принимаются помесячно и за год (скидка при годовой оплате)  
- После оплаты — автоматическая активация тарифа (Trial → Базовый/Pro)  
- Учёт подписок и лимитов по Telegram user_id

#### 3. Постепенное открытие категорий в Trial (14 дней)

- День 1–3: Гостиная (диваны прямые, угловые, кресла, журнальные столы) — ≈400–500 моделей  
- День 4–7: Кухни + столовые (столы, стулья) — +400–500 моделей  
- День 8–11: Спальни (кровати, тумбы) — +400 моделей  
- День 12–14: Остальное + новинки — +500–600 моделей  

Общий лимит скачиваний за 14 дней Trial: **100 штук**.

#### 4. Интеграция оплаты через ЮKassa

- Уже подключена ЮKassa на расчётный счёт юрлица — использовать её API v3  
- Способы оплаты на странице выбора тарифа:
  - Карта
  - СБП (по QR-коду) — основной способ для юрлиц безналично  
  - Счёт на юрлицо (по желанию — генерировать PDF с реквизитами)

**Требования к СБП по QR:**

1. При выборе «Оплатить с расчётного счёта юрлица»:
   - Показать форму (опционально): ИНН юрлица (10/12 цифр, можно пропустить)
   - Создать платёж в ЮKassa с типом `sbp`
   - Получить QR-код и ссылку на оплату
   - Отобразить:
     - Большой QR-код (PNG)
     - Кнопку «Скачать QR» (PNG-файл)
     - Текст с реквизитами (получатель, сумма, назначение платежа)
     - Таймер (QR действителен 15 минут, кнопка «Обновить QR»)

2. Назначение платежа в QR (пример):  
   «Подписка RevitBoost, тариф Базовый, email: user@example.com, сумма 990 ₽»

3. Webhook от ЮKassa:  
   - При успешной оплате — активировать тариф  
   - Отправить уведомление в Telegram (бот/TMA): «Оплата прошла, доступ открыт»

4. Если оплата не прошла за 15 мин — показать сообщение: «QR устарел, сгенерировать новый?»

#### 5. Технические требования

- **Авторизация** — через Telegram user_id  
- **Учёт подписок**:
  - `user_id` (Telegram ID)  
  - `plan` (enum: free, trial, basic, pro)  
  - `trial_start_date`  
  - `trial_downloads_used` (int, для Trial)  
  - `subscription_end_date` (для платных)  
  - `downloads_total` (для статистики)

- **Постепенное открытие категорий**:
  - Поле `unlock_day` в таблице категорий (0, 4, 8, 12)
  - Фильтр при запросе: `WHERE unlock_day <= current_trial_day`

- **Уведомления** (в Telegram-боте/TMA):
  - День 7 Trial: «Ты скачал 58 моделей. Осталось 7 дней. Скоро откроются спальни»
  - День 13: «Триал почти закончился. Продлить за 990 ₽/мес?»
  - После Trial: «Триал завершён. Продлить?»

- **Оплата**:
  - Интеграция ЮKassa API v3  
  - Создание платежа с `payment_method_data: { type: "sbp" }` и `confirmation: { type: "qr_code" }`  
  - Webhook для обработки успешной оплаты
