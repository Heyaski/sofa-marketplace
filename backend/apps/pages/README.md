# Приложение Pages - Редактирование статических страниц

Это приложение позволяет редактировать существующие страницы политики конфиденциальности и договора-оферты через админку Django.

## Быстрый старт

### 1. Примените миграции

```bash
cd backend
python manage.py migrate
```

### 2. Импортируйте существующие страницы

Эта команда скопирует контент из существующих страниц фронтенда в базу данных:

```bash
python manage.py import_existing_pages
```

После выполнения команды вы увидите:

```
✅ Создана страница: Политика конфиденциальности
✅ Создана страница: ПУБЛИЧНАЯ ОФЕРТА
✅ Импорт завершен! Теперь вы можете редактировать страницы в админке Django.
```

### 3. Редактирование страниц в админке

1. Войдите в админ-панель Django
2. Перейдите в раздел **"Статические страницы"**
3. Вы увидите две страницы:
   - **Политика конфиденциальности** (тип: privacy)
   - **ПУБЛИЧНАЯ ОФЕРТА** (тип: terms)
4. Нажмите на нужную страницу для редактирования
5. Измените HTML контент в поле "Содержание"
6. Сохраните изменения

## Важно

- Страницы уже существуют на фронтенде и продолжают работать как раньше
- Редактирование через админку позволяет изменять контент без изменения кода
- HTML контент сохраняется в базе данных и может быть отредактирован в любое время

## Структура контента

Контент страниц хранится в формате HTML с использованием Tailwind CSS классов:

- `text-2xl`, `font-semibold` для заголовков
- `mb-4`, `space-y-2` для отступов
- `list-disc`, `list-decimal` для списков
- `text-main1` для ссылок

При редактировании сохраняйте эти классы для правильного отображения на сайте.
