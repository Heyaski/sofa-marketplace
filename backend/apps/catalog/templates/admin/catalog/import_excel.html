💡 Как работает импорт

  • Первая строка файла считается заголовками
  • Система автоматически определяет колонки по названиям
  • Если товар с таким артикулом уже существует — он будет обновлен
  • Если артикула нет — поиск по названию
  • Категории создаются автоматически, если не существуют
