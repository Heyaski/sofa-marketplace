Импорт товаров из Excel файла

Формат Excel файла

Excel файл должен содержать следующие колонки (в указанном порядке):

  1. Название (обязательно) - название товара
  2. Материал - материал изделия
  3. Цена (обязательно) - цена товара в числовом формате
  4. ID изображений - ID изображений через запятую (например: img_001,img_002)
  5. ID 3D моделей - ID 3D моделей через запятую (например: model_001,model_002)
  6. ID категории - ID категории из базы данных
  7. Описание - описание товара
  8. Стиль - стиль изделия
  9. Цвет - цвет изделия
⚠️ Важно: Первая строка должна содержать заголовки колонок и будет пропущена при импорте.
ℹ️ Примечание: Перед импортом убедитесь, что все файлы с указанными ID уже загружены в раздел "Файловые ресурсы".
