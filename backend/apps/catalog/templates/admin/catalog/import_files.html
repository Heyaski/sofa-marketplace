📦 Массовый импорт файлов (изображения и 3D модели)

📋 Формат Excel файла

Excel файл должен содержать следующие колонки:

Колонка Описание Пример
A: ID файла Уникальный идентификатор (обязательно) img_001, model_sofa_01
B: Тип файла image или 3d_model image, 3d_model, изображение, модель
C: Имя файла Имя файла в ZIP архиве (обязательно) sofa_photo.jpg, model.glb
D: Описание Описание файла (опционально) Фото дивана спереди
💡 Пример Excel файла: 
ID файла    | Тип       | Имя файла        | Описание
------------|-----------|------------------|--------------------
img_001     | image     | sofa_front.jpg   | Фото спереди
img_002     | image     | sofa_side.jpg    | Фото сбоку
model_001   | 3d_model  | sofa.glb         | 3D модель дивана
model_002   | 3d_model  | chair.glb        | 3D модель кресла

📁 Формат ZIP архива

  • Все файлы, указанные в Excel, должны быть в ZIP архиве
  • Файлы могут быть в корне архива или в подпапках
  • Поиск файлов осуществляется по имени (регистронезависимый)
  • Поддерживаемые форматы изображений: .jpg, .jpeg, .png, .webp, .gif
  • Поддерживаемые форматы 3D: .glb, .gltf, .fbx, .usdz
