📦 Массовый импорт файлов (изображения и 3D модели)

✨ Автоматический импорт файлов и привязка к товарам

Система автоматически определит тип файла, создаст FileAsset и привяжет файлы к товарам по артикулу:

  • ID файла формируется из имени файла без расширения
  • Тип файла определяется автоматически по расширению
  • Автоматическая привязка: Система извлекает артикул из имени файла и ищет товар с таким артикулом
  • Если товар найден - все файлы (изображения и 3D модели) автоматически привязываются к нему
  • Поддерживаются файлы с артикулами: IMR-556065.jpg, IMR-556065(1).jpg, IMR-556065(2).jpg, IMR-556065.glb
  • Файлы могут быть в корне архива или в подпапках

SFTP (Cursor / upload3d): тот же импорт, что и ZIP выше. Положите файлы в /home/upload3d/models (или путь из UPLOAD3D_MODELS_INCOMING_DIR) и выполните на сервере: python manage.py sync_upload3d_models — либо настройте cron каждые 5–10 мин. Имя файла = код товара: Кресло4052.glb, не только артикул IMR-*.

📁 Формат ZIP архива

Просто упакуйте все файлы в ZIP архив:

  • Файлы могут быть в корне архива или в подпапках
  • Поддерживаемые форматы изображений: .jpg, .jpeg, .png, .webp, .gif, .bmp, .svg
  • Поддерживаемые форматы 3D: .glb, .gltf, .fbx, .obj, .usdz, .rfa, .dae, .3ds
  • Файлы с другими расширениями будут автоматически пропущены
💡 Примеры имен файлов:
  • IMR-556065.jpg → ID: IMR-556065, Тип: image
  • IMR-556065(1).jpg → ID: IMR-556065(1), Тип: image
  • IMR-556065(2).png → ID: IMR-556065(2), Тип: image
  • IMR-556065.glb → ID: IMR-556065, Тип: 3d_model

⚠️ Важно

  • Если файл с таким ID и типом уже существует, он будет обновлен
  • Артикул извлекается из имени файла (например: IMR-556065.jpg → артикул: IMR-556065)
