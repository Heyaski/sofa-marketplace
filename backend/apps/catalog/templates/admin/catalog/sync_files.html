🔄 Синхронизация файлов с товарами

✨ Что делает синхронизация

Система автоматически привяжет все существующие FileAsset к товарам по артикулу:

  • Извлекает артикул из ID файла (например: IMR-556065(1) → артикул: IMR-556065)
  • Ищет товар с таким артикулом
  • Привязывает все изображения и 3D модели к найденному товару
  • Создает ProductImage для каждого изображения
  • Обновляет поля товара с информацией о файлах

⚠️ Важно

  • Убедитесь, что в товарах указаны артикулы, соответствующие именам файлов
  • Артикулы должны совпадать точно (например: IMR-556065 в товаре и IMR-556065.jpg в файле)
  • Файлы с номерами в скобках (например: IMR-556065(1).jpg) привязываются к товару с базовым артикулом IMR-556065
  • Если товар с таким артикулом не найден, файлы не будут привязаны
