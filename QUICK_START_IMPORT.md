# 🚀 Быстрый старт: Импорт товаров из Excel

## Что было реализовано

✅ **Новая модель FileAsset** - хранилище файлов с уникальными ID  
✅ **Импорт из Excel** - массовая загрузка товаров  
✅ **Связь через ID** - товары связываются с файлами по ID  
✅ **API поддержка** - файлы автоматически отдаются через API  
✅ **Обратная совместимость** - старые товары работают как прежде

## 🎯 Как использовать (3 простых шага)

### Шаг 1️⃣: Загрузите файлы

1. Откройте админ-панель: `http://ваш-сайт/admin/`
2. Перейдите в **"Файловые ресурсы"** (Catalog → File assets)
3. Добавьте файлы с уникальными ID:
   - **ID файла**: `img_001` (для изображений) или `model_001` (для 3D)
   - **Тип файла**: выберите "Изображение" или "3D Модель"
   - **Файл**: загрузите файл

```
Пример ID:
img_001, img_002, img_003    ← для изображений
model_001, model_002         ← для 3D моделей
```

### Шаг 2️⃣: Подготовьте Excel файл

Используйте пример: `backend/example_products_import.xlsx`

**Структура файла:**

| Название        | Материал | Цена  | ID изображений  | ID 3D моделей | ID категории |
| --------------- | -------- | ----- | --------------- | ------------- | ------------ |
| Диван "Комфорт" | Ткань    | 50000 | img_001,img_002 | model_001     | 1            |

**Обязательные колонки:** Название, Цена  
**Опциональные:** все остальные

### Шаг 3️⃣: Импортируйте товары

1. Откройте **"Продукты"** (Catalog → Products)
2. Нажмите кнопку **"📥 Импорт из Excel"**
3. Выберите ваш Excel файл
4. Нажмите **"Импортировать"**
5. ✅ Готово!

## 💡 Полезные советы

1. **Соглашение об именовании ID:**

   - Изображения: `img_001`, `img_sofa_red`, `product_001_main`
   - 3D модели: `model_001`, `3d_sofa_comfort`, `chair_3d`

2. **Множественные файлы:**

   - Указывайте ID через запятую БЕЗ пробелов: `img_001,img_002,img_003`
   - Или С пробелами после запятой: `img_001, img_002, img_003` (система обработает)

3. **Обновление товаров:**

   - Если товар с таким названием уже есть - он обновится
   - Если нет - создастся новый

4. **Категории:**
   - Убедитесь, что категория существует
   - Или оставьте поле пустым (создастся "Без категории")

## 🐛 Проблемы?

**Проблема:** Импорт не работает  
**Решение:** Проверьте, что `openpyxl` установлен: `pip install openpyxl==3.1.5`

**Проблема:** Файлы не отображаются  
**Решение:** Проверьте, что ID в Excel совпадают с ID файлов в "Файловые ресурсы"

**Проблема:** Категория не найдена  
**Решение:** Создайте категорию в админке или оставьте поле пустым
