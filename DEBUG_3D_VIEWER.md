# 🔍 Диагностика проблемы с 3D просмотром

Если 3D модель не отображается в модальном окне, проверьте следующие моменты:

## ✅ Шаг 1: Проверьте консоль браузера

1. Откройте страницу товара
2. Нажмите F12 (или правой кнопкой → "Проверить элемент")
3. Перейдите на вкладку **Console**
4. Нажмите кнопку "Открыть 3D Viewer"
5. Посмотрите, какие сообщения появляются в консоли

**Что искать:**
- `3D Models:` - должны быть данные о моделях
- `Selected model URL:` - должен быть полный URL файла
- Ошибки CORS (Cross-Origin Resource Sharing)
- Ошибки 404 (файл не найден)
- Ошибки загрузки скрипта model-viewer

## ✅ Шаг 2: Проверьте URL файла

1. В консоли браузера найдите строку `Selected model URL:`
2. Скопируйте URL
3. Откройте его в новой вкладке браузера
4. Файл должен скачаться или отобразиться

**Если файл не открывается:**
- Проверьте, что файл действительно загружен в БД
- Проверьте, что путь к файлу правильный
- Проверьте настройки Django для раздачи медиа файлов

## ✅ Шаг 3: Проверьте данные в API

1. Откройте в браузере: `http://localhost:8000/api/catalog/products/ID_ТОВАРА/`
2. Найдите поле `asset_3d_models`
3. Проверьте, что там есть данные:

```json
{
  "asset_3d_models": [
    {
      "asset_id": "model_001",
      "file_type": "3d_model",
      "file_url": "http://localhost:8000/media/assets/model_001.glb"
    }
  ]
}
```

**Если поле пустое:**
- Проверьте, что у товара указаны ID 3D моделей в поле `model_3d_asset_ids`
- Проверьте, что FileAsset с таким ID существует в БД

## ✅ Шаг 4: Проверьте формат файла

Убедитесь, что файл имеет правильное расширение:
- ✅ `.glb` - рекомендуется
- ✅ `.gltf` - поддерживается
- ✅ `.usdz` - для iOS
- ⚠️ `.fbx`, `.rfa` - не поддерживаются для просмотра в браузере

## ✅ Шаг 5: Проверьте настройки Django

Убедитесь, что в `backend/config/settings.py` правильно настроены:

```python
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
```

И в `backend/config/urls.py`:

```python
if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

## ✅ Шаг 6: Проверьте загрузку скрипта model-viewer

1. В консоли браузера введите: `customElements.get('model-viewer')`
2. Если вернется `undefined` - скрипт не загрузился
3. Проверьте вкладку **Network** в DevTools
4. Найдите запрос к `model-viewer.min.js`
5. Убедитесь, что он загрузился успешно (статус 200)

## 🐛 Частые проблемы и решения

### Проблема: "Скрипт 3D просмотра не загрузился"

**Решение:**
- Проверьте подключение к интернету
- Обновите страницу (Ctrl+F5 для полной перезагрузки)
- Проверьте, что нет блокировщиков рекламы, которые могут блокировать скрипты

### Проблема: CORS ошибка

**Решение:**
- Убедитесь, что Django настроен для раздачи медиа файлов
- Проверьте настройки CORS в Django (если используется django-cors-headers)

### Проблема: Файл не найден (404)

**Решение:**
- Проверьте, что файл действительно загружен в папку `backend/media/assets/`
- Проверьте, что путь в URL правильный
- Убедитесь, что сервер Django запущен и доступен

### Проблема: Модель загружается, но не отображается

**Решение:**
- Проверьте, что файл не поврежден
- Попробуйте открыть файл в другом 3D просмотрщике
- Проверьте размер файла (слишком большие файлы могут не загружаться)
- Проверьте консоль на ошибки загрузки

## 📝 Отладочная информация

В режиме разработки (когда запущен `npm run dev`) в модальном окне будет показана отладочная информация:
- URL файла
- Формат файла
- Статус загрузки скрипта

Эта информация поможет быстро найти проблему.

## 🔧 Дополнительные проверки

1. **Проверьте Network вкладку:**
   - Откройте DevTools → Network
   - Откройте модальное окно 3D просмотра
   - Найдите запрос к файлу .glb/.gltf
   - Проверьте статус ответа (должен быть 200)

2. **Проверьте Elements вкладку:**
   - Найдите элемент `<model-viewer>`
   - Проверьте атрибут `src` - должен содержать правильный URL

3. **Проверьте в админке Django:**
   - Убедитесь, что FileAsset создан правильно
   - Проверьте, что файл действительно загружен
   - Проверьте, что у товара указаны правильные ID в поле `model_3d_asset_ids`

---

**Если проблема не решена:**
1. Скопируйте все сообщения из консоли браузера
2. Скопируйте URL файла
3. Проверьте, что файл доступен напрямую по URL
4. Проверьте настройки Django для раздачи медиа файлов
