# 📦 Настройка S3 хранилища для 3D моделей (Beget)

Это руководство поможет настроить загрузку 3D моделей в облачное хранилище S3 от Beget вместо локального сервера.

## 🎯 Преимущества использования S3 хранилища

- ✅ Экономия места на сервере
- ✅ Быстрая загрузка файлов для пользователей
- ✅ Масштабируемость (неограниченный объем хранилища)
- ✅ Надежность хранения данных

## 📋 Шаг 1: Создание S3 хранилища в Beget

1. Войдите в панель управления Beget
2. Перейдите в раздел **"Облако"** → **"Создать"** → **"Объектное хранилище"**
3. Выберите тариф и задайте имя бакета (только латинские символы, цифры и `-`)
4. Настройте политики доступа (рекомендуется включить публичную политику для чтения)
5. Нажмите **"Создать хранилище"**

## 🔑 Шаг 2: Получение реквизитов доступа

После создания хранилища откройте его в панели управления и найдите раздел **"Реквизиты доступа"**:

- **URL** - используется для подключения (например: `https://s3.beget.com`)
- **Имя бакета** - уникальное имя бакета (например: `your-bucket-name`)
- **Access key** - имя пользователя (нажмите на иконку 👁️ для просмотра)
- **Secret key** - секретный пароль (нажмите на иконку 👁️ для просмотра)
- **Публичный URL бакета** - URL для доступа к файлам (например: `your-bucket-name.s3.beget.com`)

## ⚙️ Шаг 3: Настройка переменных окружения

Создайте или отредактируйте файл `.env` в корне проекта `backend/`:

```bash
# Активация S3 хранилища
USE_S3_STORAGE=1

# Реквизиты доступа из панели Beget
AWS_ACCESS_KEY_ID=your_access_key_here
AWS_SECRET_ACCESS_KEY=your_secret_key_here
AWS_STORAGE_BUCKET_NAME=your-bucket-name

# Endpoint URL (из раздела "Реквизиты доступа" -> "URL")
AWS_S3_ENDPOINT_URL=https://s3.beget.com

# Публичный URL бакета (из раздела "Реквизиты доступа" -> "Публичный URL бакета")
# ВАЖНО: Указывайте ТОЛЬКО домен БЕЗ протокола (без https://)
# Используйте virtual hosted style (рекомендуется)
AWS_S3_CUSTOM_DOMAIN=your-bucket-name.s3.beget.com
```

### Пример заполнения:

```bash
USE_S3_STORAGE=1
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
AWS_STORAGE_BUCKET_NAME=sofa-marketplace-models
AWS_S3_ENDPOINT_URL=https://s3.beget.com
# ВАЖНО: БЕЗ https:// в начале!
AWS_S3_CUSTOM_DOMAIN=sofa-marketplace-models.s3.beget.com
```

## 📦 Шаг 4: Установка зависимостей

Установите необходимые библиотеки:

```bash
cd backend
pip install -r requirements.txt
```

Или установите вручную:

```bash
pip install django-storages boto3
```

## ✅ Шаг 5: Проверка настройки

1. Перезапустите Django сервер:

   ```bash
   python manage.py runserver
   ```

2. Проверьте вывод в консоли - должно появиться сообщение:

   ```
   ✅ S3 хранилище активировано: your-bucket-name
   ```

3. Если видите сообщение:
   ```
   ℹ️ Используется локальное хранилище (MEDIA_ROOT)
   ```
   Проверьте, что `USE_S3_STORAGE=1` в файле `.env`

## 🎨 Шаг 6: Загрузка файлов через админ-панель

1. Откройте админ-панель Django: `http://your-domain.com/admin/`
2. Перейдите в **"Catalog"** → **"Файловые ресурсы"**
3. Нажмите **"+ Добавить файловый ресурс"**
4. Загрузите 3D модель (`.glb`, `.gltf`, `.usdz` и т.д.)
5. Сохраните

**Файл автоматически загрузится в S3 хранилище!** 🎉

## 🔍 Проверка загрузки файлов

### В панели Beget:

1. Откройте ваше S3 хранилище
2. Перейдите в раздел **"Управление файлами"**
3. Вы должны увидеть папку `assets/` с загруженными файлами

### В админ-панели Django:

1. Откройте загруженный файл
2. Проверьте URL файла - он должен начинаться с вашего S3 домена:
   ```
   https://your-bucket-name.s3.beget.com/assets/model_001.glb
   ```

## 🌐 Настройка CORS (если нужно)

Если файлы не загружаются на фронтенде, настройте CORS в панели Beget:

1. Откройте настройки бакета
2. Перейдите в раздел **"Настройки CORS"**
3. Нажмите **"Добавить"**
4. Заполните:
   - **Origin**: `https://your-domain.com` (ваш домен)
   - **Разрешенные HTTP-методы**: GET, HEAD, OPTIONS
   - **Разрешенные заголовки**: `*` (или конкретные заголовки)
   - **Время кэширования CORS**: 3600

## 🔒 Настройка политик доступа

Для публичного доступа к файлам (рекомендуется для 3D моделей):

1. Откройте настройки бакета
2. Перейдите в раздел **"Политики доступа"**
3. Включите **"Публичная политика"**

Это позволит пользователям скачивать файлы без авторизации.

## 🚨 Устранение проблем

### Проблема: Файлы не загружаются в S3

**Решение:**

1. Проверьте правильность `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY`
2. Убедитесь, что `USE_S3_STORAGE=1` в `.env`
3. Проверьте права доступа к бакету в панели Beget

### Проблема: Файлы загружаются, но не отображаются на сайте

**Решение:**

1. Проверьте `AWS_S3_CUSTOM_DOMAIN` - должен совпадать с публичным URL бакета
2. Убедитесь, что включена публичная политика доступа
3. Проверьте CORS настройки

### Проблема: Ошибка "Access Denied"

**Решение:**

1. Проверьте правильность ключей доступа
2. Убедитесь, что бакет существует и доступен
3. Проверьте политики доступа в панели Beget

## 📝 Дополнительные настройки

### Использование собственного поддомена

Вы можете использовать свой поддомен для доступа к файлам:

1. В панели Beget создайте поддомен (например: `files.your-domain.com`)
2. Настройте CNAME запись на публичный URL бакета
3. В `.env` укажите:
   ```bash
   AWS_S3_CUSTOM_DOMAIN=files.your-domain.com
   ```

### Миграция существующих файлов

Если у вас уже есть файлы на локальном сервере, их можно загрузить в S3:

1. Используйте файловый менеджер в панели Beget
2. Или используйте AWS CLI:
   ```bash
   aws s3 sync media/assets/ s3://your-bucket-name/assets/ --endpoint-url=https://s3.beget.com
   ```

## 🔄 Отключение S3 хранилища

Если нужно временно отключить S3 и вернуться к локальному хранилищу:

1. В файле `.env` измените:
   ```bash
   USE_S3_STORAGE=0
   ```
2. Перезапустите Django сервер
