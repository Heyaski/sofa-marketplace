# 🔧 Исправление ошибки SignatureDoesNotMatch для Beget S3

Если вы получаете ошибку `SignatureDoesNotMatch` при использовании подписанных URL:

```
<Error>
<Code>SignatureDoesNotMatch</Code>
<Message/>
</Error>
```

## ✅ Решение: Правильная настройка региона для подписи

Проблема возникает из-за того, что Beget S3 использует регионы в endpoint URL (например, `s3.ru1.storage.beget.cloud`), и для правильной подписи нужно использовать соответствующий регион.

### Шаг 1: Определите регион из endpoint URL

Ваш endpoint URL: `https://s3.ru1.storage.beget.cloud`

Регион определяется автоматически из URL (`ru1`), но можно указать явно в `.env`:

```bash
# В файле .env добавьте (опционально):
AWS_S3_REGION_NAME_FOR_SIGNING=ru1
```

### Шаг 2: Перезапустите Django сервер

```bash
python manage.py runserver
```

### Шаг 3: Перезагрузите файлы

Файлы нужно перезагрузить, чтобы сгенерировались новые подписанные URL с правильным регионом:

1. Откройте админ-панель Django
2. Перейдите в **Catalog** → **Файловые ресурсы**
3. Удалите файлы с проблемой
4. Загрузите файлы заново

### Шаг 4: Проверьте URL

После перезагрузки файла URL должен содержать правильный регион в credential:

```
https://s3.ru1.storage.beget.cloud/604ac302c572-joyful-valeriy/assets/file.glb?X-Amz-Credential=...%2Fru1%2Fs3%2Faws4_request&...
```

Обратите внимание на `%2Fru1%2Fs3%2Faws4_request` в credential (это `ru1` регион).

## 🔍 Если проблема сохраняется

### Вариант 1: Проверьте правильность endpoint URL

Убедитесь, что в `.env` указан правильный endpoint URL:

```bash
AWS_S3_ENDPOINT_URL=https://s3.ru1.storage.beget.cloud
```

### Вариант 2: Укажите регион явно

Добавьте в `.env`:

```bash
AWS_S3_REGION_NAME_FOR_SIGNING=ru1
```

### Вариант 3: Проверьте ключи доступа

Убедитесь, что `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY` указаны правильно и соответствуют вашему бакету.

### Вариант 4: Переключитесь на публичный доступ (временно)

Если подписанные URL не работают, можно временно переключиться на публичный доступ:

```bash
# В файле .env
S3_FILE_ACCESS_MODE=public
```

И включите публичную политику в настройках бакета Beget.

## 📝 Дополнительная информация

- Регион определяется автоматически из endpoint URL
- Для `s3.ru1.storage.beget.cloud` используется регион `ru1`
- Для `s3.beget.com` (без региона) может потребоваться `us-east-1` или пустая строка
- Подписанные URL действительны 1 час
