ШАГ 1: ЗАГРУЗИТЕ ФАЙЛЫ С ID
────────────────────────────
1. Откройте админ-панель: http://localhost:8000/admin/
2. Перейдите: Каталог → Файловые ресурсы → Добавить
3. Заполните:
   • ID файла: img_001 (или любой другой уникальный ID)
   • Тип файла: Изображение (или 3D Модель)
   • Файл: [выберите файл]
4. Сохраните

💡 Повторите для всех ваших файлов

ШАГ 2: ПОДГОТОВЬТЕ EXCEL ФАЙЛ
──────────────────────────────

ШАГ 3: ИМПОРТИРУЙТЕ ТОВАРЫ
───────────────────────────
1. Откройте: Каталог → Продукты
2. Нажмите кнопку: 📥 Импорт из Excel
3. Выберите ваш Excel файл
4. Нажмите "Импортировать"
5. ✅ Готово!

┌───────────────────────────────────────────────────────────────────┐
│  💡 ПОЛЕЗНЫЕ СОВЕТЫ                                               │
└───────────────────────────────────────────────────────────────────┘

1. ID файлов должны быть уникальными
   Хорошо: img_001, img_sofa_red, model_chair_01
   Плохо: 1, 2, img

2. В Excel указывайте ID через запятую
   Правильно: img_001,img_002,img_003
   Тоже правильно: img_001, img_002, img_003 (пробелы обрабатываются)

3. Убедитесь, что категории созданы до импорта
   Или оставьте поле "ID категории" пустым

4. Если товар с таким названием существует - он обновится
   Если нет - создастся новый
